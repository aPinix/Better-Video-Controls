# Better Video Controls

Seek through web videos by hovering over a video and scrolling horizontally with your mouse or trackpad.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/phhigkiikolopghmahejjlojejpocagg)**

## About this repository

This is the public home for **bug reports, feature requests, and feedback** for Better Video Controls.

The extension’s source code is maintained privately and is not included in this repository.

## Features

- Horizontal scrolling to seek backward and forward through videos.
- A visual progress bar while seeking.
- Customizable shortcuts for faster or more precise seeking.
- Adjustable scroll direction.
- Support for YouTube, Instagram, TikTok, and other websites with HTML5 videos.

Compatibility may vary depending on the website and its video player.

## Getting started

1. Install the extension from the Chrome Web Store.
2. Open a webpage containing a video.
3. Hover over the video and scroll horizontally to seek.
4. Click the extension icon in your browser toolbar to customize your settings.

## Report a bug

Use the **Issues** tab in this repository to report a problem. Before opening a new issue, search existing reports and check that your extension is up to date.

To help investigate, include:

- A description of the problem.
- Steps to reproduce it.
- What you expected and what happened instead.
- Your browser, operating system, and extension version.
- The affected website or a public video URL.
- A screenshot or recording, if helpful.

Issues are public, so please remove personal information and sensitive details before posting.

## Request a feature

Have an idea? Open an issue explaining what you’d like to do, why it would be useful, and how you imagine it working.

If a similar request already exists, add a reaction or relevant details to that issue.
